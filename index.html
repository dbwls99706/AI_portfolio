deadends.dev

Structured Failure Knowledge Infrastructure for AI Agents

AI 에이전트가 이미 실패한 해결책을 반복적으로 시도하는 문제를 해결합니다. 2,000개 이상의 에러 엔트리와 43개 소프트웨어 도메인을 커버하는 구조화된 실패 지식 데이터베이스를 제공합니다.

2,000+ Error Entries
43 Tech Domains
8 MCP Tools
18+ Output Formats

Key Architecture

  • MCP Server with 8 specialized tools for intelligent error querying
  • REST API, Python SDK, CLI — multiple integration interfaces
  • ErrorCanon JSON structure: error signatures, verdicts, dead ends, workarounds
  • Error transition graphs connecting related failure patterns
  • Coverage: Python, Docker, ROS2, CUDA, Kubernetes, Go, Java, AWS 등 43개 도메인
Python MCP Protocol REST API JSON-LD OpenAPI Docker PyPI

deadends query 
# MCP Tool: search errors
from deadends import Client

client = Client()
results = client.search(
    "CUDA out of memory",
    domain="cuda"
)

for entry in results:
    print(entry.dead_ends)
    # ["Increasing swap space"]
    print(entry.workarounds)
    # ["Use gradient checkpointing",
    #  "Reduce batch size by half"]

Velog Backup

Velog 블로그 백업 서비스 — 글이 지워지기 전에

한국의 기술 블로그 플랫폼 Velog의 글과 이미지를 안전하게 백업하는 풀스택 웹 서비스입니다. GitHub OAuth 로그인, 이메일 알림, ZIP 다운로드 기능을 제공합니다.

Full-Stack Architecture
Next.js Frontend
FastAPI Backend
Supabase Database

System Architecture

  • Frontend: Next.js 14 (Vercel 배포) — SSR 기반 대시보드
  • Backend: FastAPI (Railway 배포) — 비동기 백업 처리
  • Database: PostgreSQL (Supabase) — 메타데이터 및 사용자 관리
  • GitHub OAuth 인증, 이메일 알림, 이미지 포함 ZIP 다운로드
  • Privacy-first: 사용자별 독립된 백업 데이터 격리
